# MakerPress 1.2.0 (versionCode 3)

- Golf redesign: rounded terrain textures, printed key, calculated par, short/medium/long holes, two tree types, tee and flag.
- Course mode: 3, 6 or 9 holes with a 1–4 player scorecard.
- Galaxy redesign: nebulas, asteroid fields, base, portal, key and shield/crystal/turn trackers.
- New Dungeon dice crawl, Maze, Nonogram (19 pictures, each with one logical solution) and Bingo (numbers, times tables, words, caller list).
- Share codes on every game and puzzle print; enter a code to print the same map. Daily challenge.
- Class mode: 10–40 different numbered sheets plus combined answer keys or a bingo caller list.
- Preview: actual-size and 2× zoom, paper length, dice button, copyable code.
- Printer Lab texture calibration strip and a lighter/normal/darker texture setting.
- Saved 1.0/1.1 documents still reprint exactly; old boards keep their original look.

This is still the local debug/test channel. Texture density and the new layouts have not been checked on a physical KP-1025.

# MakerPress 1.1.0 (versionCode 2)

- Golf and Galaxy: original procedural paper games with rules, score tracks and reproducible level IDs.
- New random game per queued print, unique extra copies, exact history reprints.
- Geometry, linear functions, quadratic formula/Bhaskara and physics with vector diagrams.
- Draw-the-graph and read-the-graph exercises, mixed review and separate worked answer keys.
- Kakooma-style number puzzles with one verified equation per group.
- Connect-the-dots: six original silhouettes, varied dot counts and completed-picture answers.
- Persistent PT-BR / EN switch for the interface and generated activities.
- GitHub update endpoint configured for leomelchior21/makerpress; saved documents remain compatible.

This distribution continues the existing locally signed debug/test installation. It is not a production-key release. Physical printer compatibility remains to be verified on your KP-1025.
