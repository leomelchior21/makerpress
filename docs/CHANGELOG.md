# MakerPress 1.1.0 (versionCode 2)

- Golf and Galaxy: original procedural paper games with rules, score tracks and reproducible level IDs.
- New random game per queued print, unique extra copies, exact history reprints.
- Geometry, linear functions, quadratic formula/Bhaskara and physics with vector diagrams.
- Draw-the-graph and read-the-graph exercises, mixed review and separate worked answer keys.
- Kakooma-style number puzzles with one verified equation per group.
- Connect-the-dots: six original silhouettes, varied dot counts and completed-picture answers.
- Persistent PT-BR / EN switch for the interface and generated activities.
- GitHub update endpoint configured for leomelchior21/makerpress; saved documents remain compatible.

This distribution continues the existing locally signed debug/test installation. It is not a production-key release. Physical printer compatibility remains to be verified on your KP-1025.
